# 🏪 Kantinku - Aplikasi Manajemen Kantin Sekolah

Kantinku adalah platform manajemen kantin modern berbasis web yang dirancang untuk mempermudah ekosistem transaksi di lingkungan sekolah. Aplikasi ini menjembatani pemilik stan kantin (pedagang) dalam mengelola operasional toko dan menu makanan mereka, sekaligus memberikan kemudahan bagi pembeli (siswa/warga sekolah) untuk melihat informasi stan yang sedang beroperasi secara real-time.

---

## 🚀 Fitur Utama

### 👨‍🍳 Fitur Sisi Pedagang (Mitra Kantin)
* **Autentikasi Sistem:** Fitur Register Akun baru dan Login Multi-user.
* **Manajemen Profil Stan:** Pengaturan informasi lapak meliputi nama toko, nomor kontak WhatsApp, serta kendali status operasional (*Buka/Tutup Toko*).
* **Manajemen Menu Jajanan:** Menambah, melihat, dan mengelola daftar menu jualan secara dinamis lengkap dengan harga, kategori, dan deskripsi produk.

### 🛍️ Fitur Sisi Pembeli (Siswa / Warga Sekolah)
* **Katalog Restoran Real-Time:** Menampilkan daftar stan kantin aktif beserta status operasionalnya.
* **Filter Jajanan Cepat:** Memudahkan pencarian makanan berdasarkan kategori lapak yang tersedia.

---

## 🛠️ Tech Stack

* **Framework:** Laravel 11 / 12
* **Language:** PHP 8.3+
* **Database:** MySQL / MariaDB
* **Frontend Styles:** Tailwind CSS
* **Icons:** FontAwesome v6
